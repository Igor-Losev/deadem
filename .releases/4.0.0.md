**Breaking Changes**

* `@deademx/engine`: Removed multi-threaded parsing.
* `@deademx/engine`, `deadem`, `@deademx/cs2`, `@deademx/dota2`: Added the `exports` field — only the package root is importable. Deep paths (`src/**`, `proto/**`) no longer resolve.

**New Features**

* `@deademx/engine`, `deadem`, `@deademx/cs2`: Added user commands (player input) parsing.
* `@deademx/ui`: Added Input tab.

**Improvements**

* `@deademx/engine`, `deadem`, `@deademx/cs2`, `@deademx/dota2`: Improved support for third-party bundlers (a side effect of the multi-threaded parsing removal).
* `deadem`, `@deademx/cs2`, `@deademx/dota2`: Reduced browser bundle size by ~40% (a side effect of the multi-threaded parsing removal).

**Documentation**

* `@deademx/engine`: Added code examples across the documentation.
* `deadem`, `@deademx/cs2`, `@deademx/dota2`: Refreshed performance tables.

**Examples**

* `@deademx/examples-node-cs2`, `@deademx/examples-node-deadem`: Added `109_parse_input_activity.js` — per-player input activity.
* `@deademx/examples-node-dota2`: Added `106_parse_unit_orders.js` — per-player unit orders.
* `@deademx/examples-common`: Registered new demo files.
