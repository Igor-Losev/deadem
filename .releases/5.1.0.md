**New Features**

* Added experimental `Cutter` to cut a tick window from a demo into a playable `.dem` clip.

**Deprecations**

* Deprecated passing `ParserConfiguration` to `Player` (use `PlayerConfiguration`).
* Deprecated `Parser.extract()`.

**Schema**

* Updated protobuf schemas.
* Added new message types:
  * Deadlock: `ItemAcquired`, `MapTargetingCursor`.

**Examples**

* Added demo cutting examples (`400_cut.js`) for Deadlock, Counter-Strike 2 and Dota 2.
* Registered new demo files.

**Documentation**

* Updated the documentation and tested game versions (Deadlock `6868`, Counter-Strike 2 `1.42.0.1`, Dota 2 `7.42a`).
